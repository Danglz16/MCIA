\section{Conclusión}
% Que puedo decir con base en lo que obtuve

Como podemos ver los tres algoritmos, Kruskal, Prim y Sollin, lograron encontrar
diferentes árboles generadores de costo mínimo para el mismo grafo, con costos 
totales de 25, 25 y 31 respectivamente.

Esto se debe a que cada algoritmo sigue una estrategia diferente para seleccionar 
las aristas, lo que puede llevar a resultados distintos dependiendo de la 
estructura del grafo y los costos de las aristas.
